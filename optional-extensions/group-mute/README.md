# 群聊闭嘴

WeChatGirl 0.5.11 主包默认启用「群聊闭嘴」，作用于已授权的群聊。单独导入 ZIP 时，可到「插件目录」开启并选择群聊。权限默认沿用当前微信账号已有的 DSH 管理员。也可以关闭继承，并在「额外授权成员」填写真实微信 ID，每行一个。这些成员只获得本插件的命令权限。

- `闭嘴` 使用默认时间，初始为 15 分钟。
- `闭嘴 30分钟` 或 `静音 1小时` 指定时间，单次默认最多 120 分钟。
- `解除闭嘴` 或 `开麦` 提前恢复。也可在命令前加 `/` 或艾特机器人。

暂停期间，机器人不会回复该群，也不会向该群主动发言或发送排队的语音、表情和文件。私聊及其他群聊可继续使用。静音时间可跨服务重启，静音期间的消息会保留为聊天背景。解除后，机器人用该群的人格卡发一次简短提示。DSH 暂未连接时会等恢复后生成。
