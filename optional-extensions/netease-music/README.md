# 网易云音乐

版本：1.2.0 · 可选插件，按需安装

[返回插件目录](https://github.com/my12yyds/WeChatGirl/blob/main/docs/plugins/README.md) · [下载单独插件包](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.14/netease-music-1.2.0.zip)

## 适合做什么

通过网易云音乐、QQ 音乐和酷狗查找歌曲，并读取平台链接对应的歌名、歌手与版本。

网易云站内搜索歌曲、读取歌曲与公开歌单。音乐工作台支持扫码登录，后台按账号实际权限读取音源；登录凭据只保存在本机，不交给聊天模型。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 需要账号权限时在音乐页用官方窗口登录；登录凭据仅由本机管理。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重开DSH。

## 使用例子

“搜索邓紫棋的泡沫”，或发送网易云歌曲链接后要求翻唱。

## 权限与数据

- 访问公开网页

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

在「音乐 → 歌曲搜索顺序」上移或下移平台并保存。自动搜索采用第一个有相关结果的平台，单次可指定平台。只报歌名点唱时依次找准确版本和完整音源；提供歌曲链接时保留链接指定的版本。

## 限制与排查

在桌面程序进入「音乐 → QQ 音乐与酷狗音乐账号」，在对应卡片点击「官方窗口登录」，使用平台页面提供的方式完成登录。显示「登录凭据已保存」后，可搜一首歌并点击「检查音源」确认该版本的权限。「检查凭据」核对本机是否还能读取登录信息。平台若只返回试听、要求额外验证或未给出完整音源，制作会停止并提示。三个平台可以独立登录和退出。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后从托盘完整重开DSH。
- 模型或本地环境报错：先在对应功能页做连接检测或本机试听，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
