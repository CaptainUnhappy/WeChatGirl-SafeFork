# 群聊闭嘴

在「插件目录 → 群聊闭嘴 → 配置」调整插件适用群聊、默认档位及一档时长。可选择允许 DSH 管理员控制静音，也可以填写额外授权成员的真实微信 ID。额外授权只用于静音和解除。

| 群命令 | 效果 |
| --- | --- |
| `闭嘴` | 使用配置中的默认档位，初始为一档。 |
| `闭嘴 1档` | 暂停主动接话和自动回复；只有真正艾特机器人的新消息才可以触发文字回复。默认 15 分钟。 |
| `闭嘴 1档 30分钟` 或 `闭嘴 30分钟` | 指定一档持续时长，默认上限为 120 分钟，可在设置修改。 |
| `闭嘴 2档` | 完全静音，艾特也不回复。重启后仍生效，不会自动到期，也不能直接切回一档。 |
| `解除闭嘴` | 授权成员发送这四个字即可解除任一档，可带指向机器人的艾特。`开麦` 和 `解除静音` 只兼容一档。 |

一档到期或手动解除、二档手动解除后，机器人用该群的当前人格发一次恢复提示。静音期间跳过的消息不会补回，尚未发送的旧回复也会停止。其他群聊和私聊不受影响。
