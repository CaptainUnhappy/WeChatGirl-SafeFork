# WeChatGirl 0.5.13

## 下载哪个包

| 文件 | 用途 |
| --- | --- |
| WeChatGirl-Setup-0.5.13-x64.exe | Windows x64 安装版，建议普通用户选择。 |
| WeChatGirl-0.5.13-portable-x64.zip | 便携版，完整解压后启动根目录的 WeChatGirl.exe。 |
| WeChatGirl-plugins-all-0.5.13.zip | 手动导入的插件总包。主程序已内置 17 个插件。 |
| SHA256SUMS.txt | 核对安装包和发行附件。 |

两份主包都内置第一方插件。单独的插件 ZIP 仅在需要手动安装时使用。大型语音模型仍按需下载；翻唱和按谱演唱仍需对应的本机引擎及模型。可选运行环境见 [语音组件](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.7/WeChatGirl-voice-components.zip)。

## 更新内容

- 群聊优先判断艾特或引用的对象。发给其他群友的消息只作背景；提到机器人昵称不再自动算作直接唤醒。
- DSH 工具目录增加常用中文名称和用途。管理员可用「帮我叫 DSH …」或 /dsh 交办，工具权限和原生审批仍生效。
- 声音工作室 1.5.0 支持原创中文写词、编曲、按谱演唱与混音。已用本机引擎生成约 23 秒测试歌曲，未向微信发送。
- 图片收到时只有预览图，会短暂等待并重读一次；体积允许时保留 PNG 截图的无损格式。模型会区分只有预览图、未拿到画面和识图模型不可用。
- 语音识别设置按本机和云端接口分组。云端可用服务商的 HTTPS 地址、密钥和模型 ID；需自行检测并按聊天授权。

升级前保存设置并从托盘退出旧程序，保留数据目录。完成升级后，从托盘完整退出并重新打开 DSH，再启动 WeChatGirl 服务以加载新版桥接。
