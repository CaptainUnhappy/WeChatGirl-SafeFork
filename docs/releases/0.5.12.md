# WeChatGirl 0.5.12

| 下载文件 | 用途 |
| --- | --- |
| `WeChatGirl-Setup-0.5.12-x64.exe` | Windows 安装版，推荐日常使用，内置 17 个第一方插件。 |
| `WeChatGirl-0.5.12-portable-x64.zip` | 便携版，插件相同；完整解压后运行根目录的 WeChatGirl.exe。 |
| `WeChatGirl-voice-components.zip` | 可选语音运行环境，已有环境或只用本地识别的用户不必下载。 |
| `SHA256SUMS.txt` | 检查下载文件是否完整。 |

从「能力 → 能力目录」启用并按聊天授权。已有插件及设置保持原样。首次启动只部署插件文件，不自动下载模型。DSH 仍需要单独安装和连接。

「语音音色 → 语音组件管理」可下载 SenseVoice 本机识别模型及其运行库，安装后在微信语音识别配置中选择「本机 SenseVoice（CPU）」和「检测配置」。SenseVoice 也可用于视频音轨转写。[模型许可与来源](https://www.modelscope.cn/models/iic/SenseVoiceSmall)

同一页面可下载 Breeze Q8 权重。镜像可达性随网络而异，权重不含合成引擎，也不含翻唱模型。[Breeze 权重与许可](https://huggingface.co/HoppouAI/Breeze-TTS-2.cpp)

升级前从托盘完整退出旧版并保留 data 目录。更多变化见[更新日志](../../RELEASE_NOTES.md)。
