# WeChatGirl 0.5.14

## 下载哪个包

| 文件 | 用途 |
| --- | --- |
| WeChatGirl-Setup-0.5.14-x64.exe | Windows x64 安装版，支持覆盖升级。 |
| WeChatGirl-0.5.14-portable-x64.zip | 便携版，完整解压后运行根目录的 WeChatGirl.exe。 |
| WeChatGirl-plugins-all-0.5.14.zip | 插件总包，用于在「能力」手动一键导入。主程序已包含第一方插件。 |
| netease-music-1.2.0.zip | 聊天搜歌和歌曲链接识别插件。 |
| voice-studio-1.5.1.zip | 语音工作室插件，支持三平台点歌与翻唱。 |
| SHA256SUMS.txt | 校验下载文件。 |

## 更新内容

- 外观增加「星潮特效」，包含流动极光、星尘、霓虹描边和顶栏流光。仍可选科技风与简洁版，三种风格均支持深浅主题。
- 音乐页新增 QQ 音乐与酷狗的独立官方登录，凭据由 Windows 加密保存。可调整三平台搜索顺序、指定歌曲链接并检查完整音源。
- Breeze 权重下载支持断点续传，镜像不可用时尝试官方源。
- 更新桌面、托盘、控制台和安装器图标。

升级前保存设置并从托盘退出程序，保留原来的 `data` 目录。已经连接 DSH 的用户请重开 DSH，并在 WeChatGirl 重新应用配置。QQ 音乐与酷狗的歌曲权限按平台账号判断。大型语音模型仍可在语音音色页按需下载。
